PETUNJUK MEMUTAR VIDEO BAB 1-7
==============================

1. Ekstrak seluruh isi ZIP ke satu folder.
2. Pastikan komputer terhubung ke internet.
3. Jangan membuka index.html dengan klik dua kali jika video YouTube tidak mau diputar.
   YouTube dapat menolak embed tanpa konteks HTTP/Referer.
4. Jalankan melalui server lokal:

   Windows:
     - Pastikan Python 3 sudah terpasang.
     - Buka folder website.
     - Klik address bar File Explorer, ketik cmd, lalu Enter.
     - Jalankan: py jalankan.py
     - Jika perintah py tidak tersedia, coba: python jalankan.py

   Fedora/Linux:
     - Buka Terminal di folder website.
     - Jalankan: python3 jalankan.py

5. Browser akan dibuka ke http://127.0.0.1:8000/index.html.
6. Klik Materi > pilih bab > tab Video, lalu klik tombol Play di pemutar.
7. Jika video tetap diblokir, gunakan tautan "Buka video ini di YouTube" di bawah pemutar.
   Pemutaran langsung dapat dipengaruhi oleh izin embed pemilik video, jaringan sekolah,
   ekstensi pemblokir konten, dan pengaturan browser.
