PETUNJUK DEPLOYMENT MPI HTML INTERACTIVE LAB

Deployment untuk GitHub Pages dan Vercel:
- Letakkan index.html, style.css, script.js, README.md, .nojekyll, dan PETUNJUK-VIDEO.txt di root repository.
- GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root).
- Vercel: impor repository, preset Other, Build Command kosong, Output Directory root repository.

Simulator interaktif:
- Level Pemula: puzzle tempel 3 keping (Judul -> Paragraf -> Daftar), tersedia drag-and-drop dan ketuk di ponsel.
- Setelah puzzle benar, potongan kode otomatis masuk ke editor dan panel pratinjau.
- Level Menengah terbuka setelah Pemula berhasil: gambar, tautan, dan tabel.
- Level Expert terbuka setelah Menengah berhasil: form, label terhubung, email wajib, select, dan tombol submit.
- Setiap level memberi 100 XP; progres tersimpan lokal di browser siswa.
- Panel pratinjau menggunakan iframe srcdoc tersandbox; JavaScript dan pengiriman formulir dari kode latihan dinonaktifkan.

Kuis dan ranking:
- Siswa mengisi nama dan kelas, lalu mengerjakan 19 soal pilihan ganda.
- Nilai otomatis dihitung dari 19 soal dan dashboard menampilkan Top 5.
- Ranking saat ini disimpan pada localStorage browser/perangkat yang digunakan, belum dibagikan lintas perangkat.
- Untuk ranking kelas bersama, hubungkan ke database online seperti Supabase/Firebase dengan autentikasi dan aturan akses yang sesuai.

Catatan video: pemutaran embed memerlukan internet dan izin penyematan dari pemilik video.
