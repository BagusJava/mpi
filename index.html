Bab 1: Pengenalan HTML

Apa itu HTML?

HTML (HyperText Markup Language) adalah bahasa markup standar untuk menyusun struktur halaman web. HTML menggunakan tag untuk menandai konten seperti judul, paragraf, gambar, tautan, tabel, dan formulir.

HTML berperan sebagai kerangka halaman. CSS digunakan untuk mengatur tampilan, sedangkan JavaScript menambahkan interaksi.

Contoh kode

<p>Ini contoh paragraf dalam HTML.</p>

Hasil yang diharapkan

Ini contoh paragraf dalam HTML.

Ingat: tag biasanya memiliki tag pembuka dan penutup, misalnya <p> dan </p>. Ada juga elemen kosong seperti <img>.

Bab 2: Kerangka HTML

Struktur dasar dokumen

Dokumen HTML umumnya diawali dengan <!DOCTYPE html>. Elemen <html> membungkus dokumen, <head> berisi informasi halaman, dan <body> berisi konten yang tampil di halaman.

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Website Saya</title>
</head>
<body>
  <h1>Halo Dunia!</h1>
  <p>Ini halaman pertama saya.</p>
</body>
</html>
Catatan: <title> muncul pada tab browser, bukan sebagai judul utama isi halaman. Judul utama pada halaman biasanya dibuat dengan <h1>.

Bab 3: Teks & Heading

Menyusun judul dan paragraf

Heading <h1> sampai <h6> digunakan untuk membentuk hierarki judul. <h1> merupakan tingkat judul tertinggi. Gunakan <p> untuk paragraf, <strong> untuk menandai penting, dan <em> untuk penekanan.

<h1>Profil Siswa</h1>
<h2>Identitas</h2>
<p>Nama saya Andi.</p>
<p><strong>Kelas:</strong> X PPLG 1</p>
<p><em>Saya senang belajar web.</em></p>

Hasil yang diharapkan

Profil Siswa

Identitas

Nama saya Andi.

Kelas: X PPLG 1

Saya senang belajar web.

Bab 4: List (Daftar)

Daftar berurut dan tidak berurut

<ul> membuat daftar dengan bullet, <ol> membuat daftar bernomor, dan <li> digunakan untuk setiap item daftar.

<h3>Hobi Saya</h3>
<ul>
  <li>Membaca</li>
  <li>Bersepeda</li>
  <li>Memprogram</li>
</ul>

<h3>Langkah Belajar</h3>
<ol>
  <li>Buka editor kode.</li>
  <li>Tulis HTML.</li>
  <li>Buka di browser.</li>
</ol>

Bab 5: Link & Gambar

Menghubungkan halaman dan menampilkan gambar

Tag <a> membuat tautan. Atribut href berisi alamat tujuan. Tag <img> menampilkan gambar; atribut src menunjukkan lokasi file dan alt memberi deskripsi alternatif.

<a href="https://www.google.com">Buka Google</a>

<img src="foto.jpg"
     alt="Foto profil siswa"
     width="200">
Tips: simpan file foto.jpg pada folder yang sesuai dengan lokasi file HTML, atau sesuaikan nilai src. Gunakan teks alt yang menjelaskan isi gambar.

Bab 6: Tabel

Menyajikan data dalam baris dan kolom

Tag <table> membentuk tabel, <tr> membuat baris, <th> membuat sel judul, dan <td> membuat sel data. Tabel cocok untuk data yang memiliki hubungan baris dan kolom.

<table>
  <tr>
    <th>Nama</th>
    <th>Kelas</th>
  </tr>
  <tr>
    <td>Andi</td>
    <td>X PPLG 1</td>
  </tr>
</table>

Hasil yang diharapkan

NamaKelas
AndiX PPLG 1
Tampilan tabel dapat dipercantik dengan CSS. Pisahkan pengaturan desain dari struktur HTML.

Bab 7: Form

Mengumpulkan input pengguna

Formulir digunakan untuk menerima data dari pengguna. <form> menjadi wadah, <label> memberi keterangan, <input> menerima masukan, dan <button> menyediakan tombol aksi. Tipe input antara lain text, email, password, dan date.

<form action="#" method="post">
  <label for="nama">Nama:</label>
  <input type="text" id="nama" name="nama" required>

  <label for="email">Email:</label>
  <input type="email" id="email" name="email" required>

  <button type="submit">Kirim</button>
</form>
Perlu diingat: HTML membangun formulir, tetapi penyimpanan dan pemrosesan data membutuhkan backend atau layanan yang sesuai. Contoh action="#" ini belum menyimpan data.
